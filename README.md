AI Network Security Concepts Tutor

About the Project

The AI Network Security Concepts Tutor is a Python-based web application that helps users learn basic network security concepts through a simple question-and-answer interface.

Features

- Learn network security concepts.
- Explore topics such as firewalls, encryption, phishing, malware, and VPNs.
- Ask questions using keyword-based matching.
- Simple web interface built with Flask.

Technologies Used

- Python
- Flask
- HTML
- CSS

Installation and Setup

1. Install Python.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the required package:
   
   "python -m pip install -r requirements.txt"

5. Run the application:
   
   "python app.py"

6. Open "http://127.0.0.1:5000" in your browser.

Project Status

Beginner-level prototype. The current question-answer system uses keyword matching.
